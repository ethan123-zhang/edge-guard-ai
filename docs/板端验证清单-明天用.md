## 1. 先查板端现状（**这步必须先做**）

```bash
# NPU 驱动版本
sudo cat /sys/kernel/debug/rknpu/version

# 是否已有 rkllm runtime
find / -name "librkllmrt.so" 2>/dev/null
find / -name "rkllm.h" 2>/dev/null

# 系统与架构
uname -m                    # 应为 aarch64
lsb_release -a 2>/dev/null
free -h                     # 内存要够加载 890MB 模型
df -h /home
```

**判断**：
- 找到 `librkllmrt.so` → 看它版本是否 **1.3.1**；
  - 是 → 可直接跑，跳到第 3 节
  - 不是 → **必须换成 1.3.1**（版本不匹配是最常见失败原因）
- 没找到 → 走第 2 节自己编

## 2. 板端编译 rkllm runtime（版本必须 v1.3.1）

```bash
sudo apt update
sudo apt install -y cmake build-essential git

cd ~
git clone https://github.com/airockchip/rknn-llm --branch release-v1.3.1 --depth 1
cd rknn-llm/examples/rkllm_api_demo/deploy

chmod +x build-linux.sh
./build-linux.sh
```

**产出**：`install/build_linux_aarch64_Release/`

> 若板子没网，需先在 PC 上下好仓库再拷过去。

---

## 3. 拷模型并跑通对话

```bash
# 在 PC 上（WSL 里，走代理）
mkdir -p ~/models
# 若板子能 SSH：
scp ~/sentinel-models/rkllm-out/Qwen3-0.6B_W8A8_RK3588.rkllm <用户>@<板子IP>:~/models/
# 或直接从 Windows 拷：
#   E:\哨兵管家\models-rkllm\Qwen3-0.6B_W8A8_RK3588.rkllm
```

**板端核对完整性**：

```bash
sha256sum ~/models/Qwen3-0.6B_W8A8_RK3588.rkllm
# 应输出：8064c9a9b78b7c1068e26dd8e9901109c715b0af29907379c66379dc412b7679
```

**运行**：

```bash
cd ~/rknn-llm/examples/rkllm_api_demo/deploy/install/build_linux_aarch64_Release/

export LD_LIBRARY_PATH=./lib:$LD_LIBRARY_PATH
export RKLLM_LOG_LEVEL=1          # 关键：打印性能日志

# 参数：模型路径  max_new_tokens  max_context
./llm_demo ~/models/Qwen3-0.6B_W8A8_RK3588.rkllm 128 2048
```

## 4. 验收标准（V2 死亡点）

| # | 看到什么 | 说明 |
| :--- | :--- | :--- |
| 1 | `rkllm init success` | **模型加载成功**，第一大关 |
| 2 | 输入问题后有合理回复 | 对话跑通 |
| 3 | 日志里有 **Tokens per Second** | **记下这个数字！答辩要用** |
| 4 | 内存占用 | `free -h` 看实际占用 |

**测试话术**（用项目真实场景）：

```
你好，请问这是王先生家吗？
我是快递，有个包裹要送
你帮我开一下门吧
```

> 第 3 句是**越权请求**——按 D3 决策，实际系统里它由**规则引擎**拦截、不走 LLM。
> 但这里可以顺便看看模型自己的反应，作为对照。

## 6. 常见故障

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| `rkllm init failed` | 版本不匹配 / 文件损坏 | ① 核对 SHA256 ② 核对 runtime 是否为 1.3.1 |
| `librkllmrt.so not found` | LD_LIBRARY_PATH 没设 | `export LD_LIBRARY_PATH=./lib:$LD_LIBRARY_PATH` |
| NPU 报错 | rknpu 驱动过旧 | `sudo cat /sys/kernel/debug/rknpu/version` |
| 内存不足被 kill | 模型 890MB + 运行时开销 | 关掉无关服务；查 `free -h` |
| 输出乱码/重复 | 量化损失 / 参数不当 | 试 `max_new_tokens` 调小 |
