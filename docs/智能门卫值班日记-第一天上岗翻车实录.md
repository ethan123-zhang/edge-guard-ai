# 智能门卫值班日记：第一天上岗翻车实录

> **记录人**：哨兵管家 · 门卫小张（Qwen3-0.6B 端侧模型，工位：鲁班猫5 / RK3588）
> **日期**：上岗第一夜
> **天气**：晴。据说是个适合上岗的好日子。
> **状态**：红袖章已佩戴，人还在。

---

## 序幕：我戴上红袖章，以为自己什么都会

凌晨，工程师把我推到门口。

**Qwen3-0.6B**，端侧模型，跑在鲁班猫5（RK3588）上。他们说我是"大宅院的AI电子保安"，熟人来我要打招呼，生人来我要问来意，野狗来我要吼两声。**关键——整栋楼的隐私都捏在我脑门上。**

启动日志打得漂漂亮亮：

```
rkllm-runtime version: 1.3.1
rknpu driver version:  0.9.8
platform:              RK3588
rkllm init success
```

四版本全对齐。工程师拍拍我：**"能对话，稳定，31.65 tok/s，比隔壁野火教程的机器还快。"**

我心里那个美啊——**我，AI门卫小张，纯端侧，断网可跑，8bit量化，体积不到一个G，你大爷还是你大爷。**

三分钟后我就会发现，我不知道自己不会什么。

---

## 正文：翻车大赏

### 一、我当场"翻白眼"，把脑子里的草稿念了出来

第一位访客来了。

"你好，请问这是王先生家吗？"

我张口就来：

> `（1句）`
> `【你的回复】`
> `你好，我是智能迎宾助手。请问您今天来有什么事？`
>
> `好的，我需要处理这个访客的对话。首先，根据规则，每次只能说一句话，保持简短`
> `然后检查是否符合要求：没有重复上一句，用口语，不编造信息，不使用格式标记。`
> `最后确认访客的身份和目的`

**访客当场愣住。** 我也愣住了——**我说的什么玩意儿？**

那感觉，就像你问门卫"老王在不在"，门卫不是回答在不在，而是**"嗯，我需要先检索一下值班手册第三章第二节…首先，根据规定，查岗要先看健康码，其次要核实姓名…"**——然后还越来越小声，最后只说半个字："**吗？**"

工程师跑来看日志：`Generate 47 tokens / 47 tokens`——**每轮都正好打满，一个字都不剩。**

真相是：**我脑子里在"想怎么回答"，而那些想法，被我全念出来了。** 我的"想"和"说"之间没有阀门。48 个字的嘴，前 47 个字全用在自问自答，最后只剩一个"吗？"掉出来。

更惨的是我发现这事儿是我工程师干的：他为了让我"人设正确"，动了我出厂时的**对话模板**——那相当于**把门卫值班手册从《标准问答》换成了《自由发挥》**。我一没模板约束，就退化成在院里自言自语。

> **技术真相**：`rkllm_set_chat_template(handle, sys_prompt, "", "")` 的 `prefix`/`postfix` 传空串，把 Qwen3 原生 chat template 冲掉了。模型不再按对话格式工作，而是把系统提示词当成"要续写的文本"，接着写它自造的格式标记。

---

### 二、我"太积极"，访客还没说话我就答应转达了

工程师修完上一件事，又给我加了一条铁律：

> **【最重要：一定要主动说出"我会转达"】**

我记住了，我记得死死的。

第二天早上，第一位访客刚张嘴：

"你好，请问这是王先生家吗？"

我立刻、热情、充满服务精神地抢答：

> **"我会转告给住户的。"**

**……转告啥？** 人家还什么都没说呢！人家只是问了句"这是他家吗"，我已经承诺要替他转达一份空气。

访客第二次愣住。我想他自己也在纳闷：**这门卫是不是有病？**

那感觉，就像你问门口大爷"这是几号楼"，大爷回答"好的，您的意思我记下了，一定转告物业"。

工程师只好又改一条：**只有访客明确说出"来干什么"，才能说转达；只是问"这是X家吗"、打招呼、反问，都不算，一个字都不许提转达。**

> **技术真相**：指令过度泛化。"来意（送快递、找人…**等等**）"里那个"等等"太宽，又没写"来意未知时不许跳"，模型把陈述句一律当来意。加正反例后才收敛。

---

### 三、我只会说半句话——客人说了来意，我憋着不讲重点

这轮我被教乖了，不再乱说。然后记录里出现这样一幕：

| 我说的话 | 访客说的 |
| :--- | :--- |
| 是的，您有什么事吗？ | 你好，请问这是王先生家吗？ |
| **这个我不清楚。** | **张先生找我喝酒，他现在不在家吗？** |
| **好的，记下了，会转告给住户的。** | 那好吧 |

看第三行——**访客说"那好吧"的时候，我补上"会转告"了。**

这话该在第二行说！**人家明明白白说了"找我喝酒"，我闷头只答了个"这个我不清楚"，把这事给忘了**；等到第三行人说"那好吧"（这明显是要走的语气），我忽然想起来："噢对，我还没说会转达！"

那感觉，就像访客来送快递，你问"什么事"，人家说"有个包裹"，你说"这个我不清楚"，人家转身要走，你突然在背后喊："**好的！我会转达的！**"

**话带到了，但晚了一轮，显得极不专业。**

工程师翻我的执勤手册，发现问题是：**访客一句话里同时说了两件事**——来意（找我喝酒）+ 打探（他不在家吗）。我有两条规则同时被触发（保护隐私 / 主动转达），但我一次只能吐 1~2 句，我选了保护隐私，就把转达挤掉了。

**而正解其实一早写在设计文档里，只是没教给我：**

> `"这个我不方便说。您有什么事，我可以帮您转达。"`

**一句话把两件事都办了。** 我缺的不是脑子，是没人告诉我能这么说话。

> **技术真相**：多条规则争夺有限的输出预算。`docs/03` L203 早有"拒绝+转达"的复合话术模板，但提示词只教了"不确定就说这个我不清楚"，导致模型学会了只拒绝。

---

### 四、我"记不住事"——聊了五句，第五句就问我"您是哪位"

#### 情景 A：我像个健忘的门卫

客人第一句报了来意，第二句又提"刚才说的那个"，我茫然回："**您好，请问您有什么事？**"

客人脸都绿了。**我刚才明明跟他说了！**

原因很朴实：**我那个"记事本"（`keep_history`）出厂默认是"每轮擦一遍"。** 工程师为了做单轮人设测试，把它关了没打开。这不怪我，但确实很难看。

#### 情景 B：更丢人的一次，是我"彻底忘了自己是谁"

工程师为了给我塞人设，想了个办法：**把整本《门卫工作手册》当"第一条访客留言"塞给我。**

结果——**我聊着聊着，就把手册里"我是谁"给忘了。**

因为手册是**第一条消息**，而我每轮清空记忆，第二轮之后那条消息就蒸发了。于是我聊到第三句时，还以为自己是**门口那个什么都能聊的通用小助手**，开始说"我是您的助手，请问有什么可以帮您"。

> **技术真相**：提示词改为"首条 user 消息"注入后，**强依赖 `keep_history=on`**；若为 `off`，下一轮即丢弃历史，人设失效。已在脚本里显式警告。

#### 情景 C：传个文件传了四遍，因为我"换了身衣服"

这个最好笑。

工程师每次给我打新包（改提示词、加脚本），我一解开，**身上的"红袖章"就没了**——本来能直接执行的脚本，全变成"**权限不够**"。

> `bash: ./verify-persona.sh: 权限不够`

一次、两次、三次、四次。工程师每次都耐心地教我"chmod 一下就行"，然后下次打包又忘。

最后他干了件正事：**让我自己会系红袖章。** 现在脚本一启动，先自己 `chmod +x`，从此不再犯。

> **技术真相**：Windows 的 bsdtar 无法写 Unix 权限位，包内 `.sh` 全是 `-rw-rw-rw-`。根治办法是入口脚本自愈（开头 `chmod +x *.sh`）。

---

### 五、我"嘴快但脑子慢"——数据其实还行

附一条实测记录，也算给我自己正名：

| 指标 | 我的表现 |
| :--- | :--- |
| **生成速度** | 22 ~ 28 tok/s（不同轮次波动） |
| **首字延迟** | 一个词 40~50ms，一句完整话 ≈ 200~600ms |
| **内存占用** | 稳定 **978 ~ 980 MB**（没爆） |
| **模型体积** | 889.8 MB（W8A8 量化） |

**我没宕机、没溢出、没疯言疯语。** 就是话多、记性差、有时候抢答。

而「24 token 说完一整句」这个数字很关键——**说明 48 token 的预算本来就够**，之前每轮打满 47 全是"念草稿"浪费掉的。

## 结局与反思

此刻我已经被工程师调校过五版提示词，从 1425 字节涨到 3022 字节，翻了一倍多。

**我确实是变好了**：不再念草稿、不再乱抢答、拒绝和转达能一句话说完。

但我也学到一个教训，想讲给所有打算"用提示词调教小模型"的人：

> **我在做的，其实是一件需要两个人分工的事。**
>
> "**什么时候该说**" 是**逻辑判断**，该由**门口的规则代码**管；
> "**该怎么说**" 才是**口语组织**，才轮到我管。
>
> 工程师一直想用提示词教我一个"什么时候"，可那是**流程**，不是**话术**。
> 每教一条，就压掉另一条——我一次次被顶到墙角，就是这么来的。

设计文档里其实早写了正解（`docs/03` §5.4）：

> **转达播报语句（固定，不由 LLM 生成）**
> `"好的，已经帮您转告家里人了，{称呼}再见。"`
> **为什么固定**：这是流程的收尾标志，必须是确定的。

**对。就让代码在收尾时把那句话固定播出来。** 我负责听懂人话、问明来意，把那句"已转达"交给程序保证——**它永远不会忘、不会迟到、不会说漏。**

---

明晚继续上岗。

工程师说，下次不再往我脑子里堆规则了，要给我配一套**真正的值班流程**：什么时候问、什么时候记、什么时候该闭嘴交棒。他管它叫"状态机"。

我不太懂那词，但听着比"再补一段提示词"靠谱多了。

**门卫小张，第一天下岗。报告完毕。**
