输入：U盘系统上的USB摄像头，或明确标注的板端OpenCV样例。输出：采集与检测指标、本地测试事件、验收JSON和日志。不输出或归档摄像头图像，不发送数据到鲁班猫5。

## 【核心算法逻辑伪代码】

```text
V4L2打开摄像头 → 请求分辨率 → 预热 → 固定次数采集
每个有效帧 → Haar检测 → 分别记录采集与检测耗时
finally释放设备 → 写JSON
本地业务验收 → 跟踪确认 → null出口，或仅写样例JSONL
```

## 【异常与边界条件】

- 诊断脚本退出0只表示采集检查通过，检测/识别结果须分别查看JSON字段；完整身份识别始终标记未验证。
- 缺少Haar时仍可验证采集；检测异常不能当成正常“0张脸”。
- 脚本读帧阻塞由外层 timeout 控制；JSON父目录必须已存在。
- CUDA设备数量检查返回0，本轮没有GPU加速验收结论。
- 已补齐现场真人检测正例；未完成真人到访事件触发、熟人注册、模型推理、长时间稳定性和跨板联调。
