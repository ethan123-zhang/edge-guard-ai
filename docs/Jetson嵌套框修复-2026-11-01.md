# Jetson Haar 嵌套框修复与验收

范围：Jetson 单板、Haar 降级路径；Codex 定义规则并独立验收，DeepSeek 限定实现。无截图、无跨板发送、不升级环境。

## 【输入输出定义】

输入为 Haar 的同帧 FaceDetection 列表。输出为保留的原检测对象，不修改输入或对象元数据。新增纯函数 suppress_nested_detections，接入 HaarDetector.detect；不修改 YuNet、跟踪器、配置或确认门槛。

## 【核心算法逻辑伪代码】

```text
丢弃非正面积框
按面积降序及坐标确定性排序
候选面积 <= 已保留框面积的 0.5，且交集/候选面积 >= 0.9：抑制
其余保留；返回时保持输入顺序
```

独立诊断回放：2026-10-31 原始40帧经现有跟踪器产生2事件（第3、7帧）；上述候选规则产生1事件（第3帧），抑制3框。此为规则假设验证，不是现场准确率或身份识别验收。

## 【异常与边界条件】

保留单独小脸、相邻两脸和未达到覆盖率/面积比条件的部分重叠框。同尺寸重复框不在本轮处理。嵌套是几何线索，不证明误检；真实人脸若严重嵌套，仍有误抑制风险，须现场验证。保持确认3帧、TTL2秒、冷却10秒。未知轨道不是跨轨身份；现有累计计票与连续帧语义的差异另案处理。

## 【验收测试用例】

- 嵌套框正反输入顺序、多层嵌套、0.9/0.5阈值边界及略越界。
- 空输入、单框、无效宽高、输入不变和对象元数据保留。
- Haar detect 集成、相邻双人/部分重叠不误合并。
- 短遮挡 TTL 内不重复；TTL 过期重入可产生新的未知轨道事件。
- 公开夹具只含相对时间与原始框，回放2→1事件、第3帧触发、抑制3框。
- 原生 Python3.6 完整测试；板端失败测试与修复后测试；文件 SHA256 一致。
- 真人稳定单人、相邻双人、遮挡重入另行同步采样；未测则明确记未通过验收。
