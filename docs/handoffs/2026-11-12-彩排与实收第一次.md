## 关键发现

1. **熟人识别在阈值边缘**：同一人四次 `confidence` = **0.736 / 0.588 / 0.496 / 0.351**，阈值 `match_threshold=0.363`（`vision/config/base.yaml:40`，board 未覆盖）。0.351 那次记成陌生人，演示时「熟人记忆」可能失败。
2. **注册距离 ≠ 演示距离（16:3x 已修正）**：原以为演示位是 1.5–2 m，实测**演示位就是约 1 m**
   （16:26 重采框高 286–296 px；15:2x 首次注册 326 px，同一距离量级）。16:26 已在演示位重采
   `p_10001` **5/5 帧**（质量 0.044–0.045），重采后同位置置信度 **0.432 / 0.480 / 0.650 / 0.658 /
   0.744 / 0.892** —— 全部过阈值，但最低 0.432 只比 0.363 高 19%，余量仍偏小。
3. **早先"演示位识别失效"是误判（已推翻）**：16:15 采集窗口里那 6 条陌生人（0.075–0.223）
   是画面里的**第二位未注册同学**，而且当时为了采样本我把关联层关了、cooldown 改 6 s，
   同一个人被碎片化成多条 —— 不是熟人 A 因距离认不出来。A 在 16:10–16:12 同一位置是
   `0.658 / 0.650 / 0.432`（都认对了）。
3. **黑帧假事件已定位并修复、实机验过**（16:1x，详见[黑帧假事件](../黑帧假事件-2026-11-12.md)）：
   14:27 那条"全黑照片却有人脸框"的到访不是 overlay 造成的 —— 抠掉框后重跑生产检测器，
   板端 CPU dnn 与 PC 一致吐出 `score=0.6315`、`bbox=(110,-7,1094,748)`。根因是那张帧为
   "暗底 + 一侧光晕渐变"（std 6.65 过了 `blank_std=2.0`，但拉普拉斯方差只有 3.60）；
   已加帧级细节判据 `detection.texture_min=20` 并部署上板。**16:10:18–16:10:50 实机遮镜头
   约 32 s：800+ 帧全部跳过、0 条上报、看板库 6→6 不变**（遮挡初期 `std=17.90`，旧判据本来
   就会放行），16:10:55 拿开后立刻恢复识别。
4. **本机代理坑**：shell 里 `HTTP_PROXY=http://127.0.0.1:7522`，访问板端必须 `curl --noproxy '*'`，否则 403（会被误判成服务故障）。
5. **jetson 没有免密 sudo**：`systemctl restart sentinel-vision` 会报 "Interactive authentication
   required"，`sudo -n` 也要密码。unit 是 `User=jetson` + `Restart=always`，所以重启走
   "`kill -TERM $(systemctl show -p MainPID --value sentinel-vision)` 让 systemd 拉起"，
   约 15 s 回来（本轮 16:05:48 实测）。Jetson sudo 密码见 `PROGRESS.md`（板子关机那条），
   有密码时可正常 `systemctl stop/start`（16:25 重采就是用它停的服务）。
6. **手机锁屏实收 + D1 拍板（16:3x–16:5x）**（详见[手机锁屏实收](../手机锁屏实收-2026-11-12.md)）：
   - 前置坑：vivo 需手动开「企微通知+锁屏通知 / 后台耗电 / 企微内新消息提醒」三处，
     否则板端 outbox 记 `sent`、群里也能看到，但锁屏一条都不弹。
   - **S1（无看板在线）通过**：16:40:40 告警 / 16:40:58 汇总，锁屏手机都收到。
   - **S2（PC 投屏看板在线）未修时失败**：16:43 两条 `sent` 但锁屏手机一条没收到 ——
     `CompositeAdapter` 首个通道成功即返回，LAN 成功后企微根本没被调用。
   - **已按 D1-a 改成 fan-out**：两路都投、任一成功即送达、单路失败只记日志；`pytest master`
     53 passed，已部署鲁班猫（md5 `c470974d…` 一致）并重启；16:46 复测 **PC 看板 + 锁屏手机都收到**。
   - 照片可达：`/api/visits/<id>/photo` 带 token 200 `image/jpeg`、不带 token 401。
