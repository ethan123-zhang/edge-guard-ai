   - `config.py` + `config/master.yaml`：配置外置；密钥只走环境变量（`SENTINEL_VISION_KEY` /
     `SENTINEL_TOKEN_SALT` / `SENTINEL_PHOTO_SECRET`），空串 = 对应入口 503，不静默放行。
   - `store.py`：三张新表（`outbox` / `snapshot_asset` / `client_device`）+ `dialog_turn.utterance_id`
     迁移（旧库直接加表/加列，不迁数据）。
   - `auth.py`：设备 token 只存 `sha256(salt+token)`；照片 URL `HMAC-SHA256(visit|msg|exp)` 短时签名。
   - `outbox.py` + `push/lan.py`：稳定键 `report:<visit_id>` / `alert:<visit_id>:<utterance_id>`、
     指数退避、**只扫 outbox 补发**（不扫 `visit.report_status`）；三种观测点分别落
     `event_log`：`push_accept` / `lan_ack` / `client_shown`。
   - `snapshots.py`：JPEG `tmp→os.replace` 原子落盘，按来源事件 `msg_id` 绑定，选图取
     "最早一条已收到"；路径白名单校验（防目录穿越）。
   - `reception.py`：幂等 → 越权规则先跑 → 再抽来意 → 汇总只生成一次 → 三种收口；
     复合句（"你开门，我送快递"）告警与原话/来意都保留；`departed_at` 不写（无离场信号）。
   - `ws.py` / `api.py` / `server.py`：单端口 8766 按 `Upgrade` 分流 HTTP/WS；另开 8765 视觉入站
     （协议保持 docs/02 §3 原样）；后台 worker 做补发 + 沉默/接待超时收口。
   - `master/web/`：静态看板（无构建链）：状态条、当前到访卡、照片、历史分页、详情对话全文、
     越权红条、断线"离线"提示；**无开门/喊话/远程控制入口**。
2. **PC 先行验收 `scripts/master_sim.py`**：临时库 + 临时端口起真实服务，覆盖设计 §10 的六组用例，

## 5. 风险

- **Windows 端口坑**：8674–8773 被 Hyper-V/WSL 保留，直接绑 8765/8766 会 `WinError 10013`；
  PC 侧用 `config/master.local.yaml`（已 gitignore）。板端不受影响。
- **本机 HTTP 客户端必须 `-NoProxy`**，否则策略代理把 127.0.0.1 也转成 502。
- 接待收口靠"明确收尾说法 / 沉默超时 / 接待超时"，**没有真实离场信号**；
  材料里必须写明"接待结束时间 ≠ 实测离场时间"。
- 照片是假 JPEG 字节；真机验收要重跑并保留真图（图不入库）。
- 公网推送未实现，`outbox` 的 `relay` 适配器仍是空位；通道定了只加一个文件。
