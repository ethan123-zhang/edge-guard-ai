## 坑（已踩过，别再来一遍）

- 板上不加 `OPENBLAS_CORETYPE=ARMV8` 会 `Illegal instruction`。
- **OpenCV 4.1.1 批量 dnn 会把同一批特征塌成同一个**，且状态粘住；CPU 路径必须 1 张 1 张喂
  （`DnnRunner.max_batch = 1` 已钳，`recognizer_batch` 只对 TRT 生效）。详见 P1 文档。
- PC 的仓库路径是中文，`cv2.dnn.readNetFromONNX` 读不了 —— PC 只跑 `legacy`；
  要验 ONNX 路径请把模型拷到 ASCII 目录或直接上板。
- P0 的 `trt_run_only = 21.50 ms` 与 CPU 前向混跑有关，单独比 engine 用
  `pipeline-breakdown-2026-11-07.json` 里的口径（15.0 ms 整段）。
- engine 与 TensorRT 版本/设备绑定：换板或升级 JetPack 要用 `trt_regression.py` 重建，
  sidecar 会主动拦下哈希/版本不符（`auto` 下退 CPU，`trt` 下报错）。
