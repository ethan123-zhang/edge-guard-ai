## 4. 公网入口（已完成并验收）

```
手机 4G ──https──▶ Cloudflare 边缘 ──加密隧道(板子主动连)──▶ 鲁班猫 127.0.0.1:8766
```

- **脚本**：`scripts/board_tunnel.sh`（仓库）→ 板上 `/home/cat/sentinel-master/scripts/board_tunnel.sh`
- **服务**：`scripts/systemd/sentinel-tunnel.service` → `/etc/systemd/system/`，`enable --now`，`Restart=always`
- **取地址**：`cat /home/cat/sentinel-master/data/public_url.txt`
- **地址会变**：快速隧道每次重连换 `https://xxx.trycloudflare.com`；脚本在拿到新地址后
  ①写 `data/public_url.txt`；②用板端 `master.local.yaml` 的企业微信 webhook 推一条（实测 `errcode:0`，
  用户微信里会收到）。本轮重启了两次隧道 + 一次整机 reboot，都自动通知了新地址。
- **整机 reboot 实测**：板子 **40 秒**回来，`sentinel-master` 与 `sentinel-tunnel` 都自动 `active`，
  新地址 `https://plots-cancelled-gibson-collecting.trycloudflare.com` 于 21:14:45 自动推送到企业微信。
- **安全**（已落地）：HTTPS + WSS；数据接口要 Bearer token；板端 `config/master.local.yaml` 加了
  `security.health_requires_token: true`（无 token `401`、有 token `200` 实测）；8765 视觉入站与 SSH 不在公网。
- **固定网址**（可选，未做）：要 Cloudflare 账号 + 域名，改命名隧道 + 可选 Cloudflare Access；
  步骤写在 `docs/04-部署与运维.md` §4.5。

**装 cloudflared 的关键经验**：GitHub 直连只有 ~10 KB/s（36 MB 要 1 小时）；
Cloudflare 官方源 `pkg.cloudflare.com` 实测 **18 MB / 7 秒（2.47 MB/s）**：
`https://pkg.cloudflare.com/cloudflared/pool/main/c/cloudflared/cloudflared_<版本>_arm64.deb`。

## 5. 真机 4G 实测（关键证据）

- 手机 WiFi 关、移动数据开（`settings get global wifi_on` → `0`，`mobile_data` → `1`）。
- APK 里把服务器地址从 `http://192.168.5.11:8766/` 改成公网 https 地址 → 看板完整加载：
  值守状态、当前访客、带人脸框照片、自称/来意/说了什么、键盘接待入口。
- 之后按约定把地址改回局域网（演示用），关掉 WiFi 重新打开，手机自动连回校园网 `192.168.5.12`，
  局域网看板正常。

**adb 操作坑（下次直接用）**：

- APK **不可调试**（`run-as` 报 `package not debuggable`），改配置只能走 App 原生设置页。
- 默认输入法是讯飞中文，`input text` 会被候选拦成乱码 → 先 `input keyevent 204`（切换语言）再输入。
- adb 显示 `unauthorized` 时先点手机弹窗允许；仍不行就 `adb kill-server && adb start-server`。
- 设置页控件坐标（1260×2800 截图坐标系）：URL 框 `(630,468)`、token 框 `(630,658)`、保存 `(630,849)`。
