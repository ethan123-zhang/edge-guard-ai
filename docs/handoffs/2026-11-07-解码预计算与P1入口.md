  不能拿「速度变快」当验收通过。

  但不是官方保证的 API 组合；P2 要再跑一次全量。
- 视频/模型证据在忽略目录 `logs/`，`docs/data` 只存汇总数与逐帧结果，不含帧图像或特征。
