## 8. 风险 / 注意

- **不要用 ping 判板子存活**（本机网络层会伪造成功），只看 SSH banner/kex。
- Jetson 跑任何 OpenCV/numpy 脚本都要 `OPENBLAS_CORETYPE=ARMV8`。
- Windows 8674–8773 被 Hyper-V/WSL 保留：本机绑 8765/8766 会 `WinError 10013`，
  PC 用 `config/master.local.yaml` 覆盖 18766/18765；本机 HTTP 客户端要 `-NoProxy`。
- 鲁班猫 Python 3.14：`master` 只用 stdlib 能跑；以后装 Vosk/云 ASR SDK 需确认有 3.14 wheel。
- 演示数据是**模拟访客**（`temp/sim_visit_photo.py` 生成），材料里必须写明；照片是合成图。
- 演示 token（`phone-vivo`）已出现在对话与板端库里，正式演示前建议换 `token_salt` 重签。
- 板端密钥在 `~/sentinel-master/config/master.local.yaml`（不在 git）：`vision_key=vision-20261111` 等。
