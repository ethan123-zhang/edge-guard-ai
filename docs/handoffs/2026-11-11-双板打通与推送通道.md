## 5. 风险

- **不要用 ping 判板子存活**（本机网络层会伪造成功），只看 SSH。
- Jetson 上任何 Python 脚本忘了 `OPENBLAS_CORETYPE=ARMV8` 都会 `Illegal instruction`。
- 鲁班猫 Python 3.14 很新：目前 `master` 只用了 stdlib，能跑；以后装 Vosk / 云 ASR SDK 要确认有 3.14 wheel，
  否则用 venv 降级到 3.12 或改用 CLI。
- 企业微信 20 条/分钟；公网通道只发文字摘要，原图仍走内网看板（隐私面也更小）。
- 场景是实验室桌面：**验收材料里要写清"模拟到访"**，不能声称门口实测。
