## 4. 双板自启动（systemd）

两板都有 systemd（鲁班猫 259 / Jetson 237），sudo 密码分别是 `lubancat1` / `yahboom`。

- 鲁班猫 `/etc/systemd/system/sentinel-master.service`：
  - `User=cat`、`WorkingDirectory=/home/cat/sentinel-master`、`ExecStart=/usr/bin/python3 -m master.server`、`Restart=always`
- Jetson `/etc/systemd/system/sentinel-vision.service`：
  - `User=jetson`、`WorkingDirectory=/home/jetson/sentinel-vision`、`EnvironmentFile=~/sentinel-vision/.env`、
    `Environment=OPENBLAS_CORETYPE=ARMV8 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1`、
    `ExecStart=/usr/bin/python3 -u scripts/vision_sim.py --profile board --no-window --source 0`、`Restart=always`
- unit 文件源在仓库 `temp/sentinel-master.service`、`temp/sentinel-vision.service`（temp 已 gitignore；
  要长期保留应移到 `scripts/systemd/`）。

**日志位置变了**：服务由 systemd 托管后输出进 journal，不再写 `logs/vision.log` / `master.log`：
`journalctl -u sentinel-vision -n 50 --no-pager`、`journalctl -u sentinel-master -n 50 --no-pager`。
