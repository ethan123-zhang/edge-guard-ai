# 质量筛选与保守参考策略评估（2026-11-06）

结论：**单一全局余弦阈值确实不可用，但「质量门控入册 + 保守参考库 + 边距规则」在现有公开视频上把两个身份分开了。** 这是同一视频时间切分的探索性结果，不是独立素材验收，不能据此冻结生产门槛。生产跨轨关联仍未启用，整体可靠性仍未通过。

## 质量指标定义

对每张检出脸，除检测分外计算四个可解释指标：

| 指标 | 定义 | 观察分布（494 脸） |
| --- | --- | --- |
| `score` | YuNet 置信度 | 0.9007 / 0.976 / 0.998 / 0.9995（min/p05/median/p95） |
| `width` | 框宽（像素） | 97.5 / 129.1 / 134.7 / 140.2 |
| `yaw_proxy` | 鼻尖相对两眼中点的水平偏移 ÷ 眼距 | 越大越接近侧脸 |
| `align_rms_norm` | 五点相似变换拟合残差 RMS ÷ 眼距（无量纲） | 0.078 / 0.29 / 0.45 / 0.66（min/p05/median/p95） |

`align_rms_norm` 是"关键点几何与正脸模板的吻合度"：轮廓、低头、遮挡都会把它抬高。它是姿态一致性代理，不是身份证据。

## 结果一：单一阈值/常见质量门都不能分开

同侧对=正样本（固定构图左右=两个身份），异侧对=负样本。判据：同侧最低余弦 > 异侧最高余弦才可能用单一阈值。

| 门 | 保留脸 | 同侧最低 | 异侧最高 | 间隔 | 可分 |
| --- | --- | --- | --- | --- | --- |
| 无 | 494 | 0.0029 | 0.3869 | −0.384 | 否 |
| score ≥ 0.98 | 466 | 0.1162 | 0.3736 | −0.257 | 否 |
| score ≥ 0.99 | 459 | 0.1271 | 0.3489 | −0.222 | 否 |
| yaw ≤ 0.22 | 44 | 0.0413 | 0.3252 | −0.284 | 否 |
| width ≥ 56 px | 494 | 0.0029 | 0.3869 | −0.384 | 否（全部达标） |
| **rms_norm ≤ 0.10** | **25** | **0.6240** | **0.2046** | **+0.419** | **是（仅 5% 覆盖）** |

- 最差同侧对是 21.5s（yaw 0.55，近侧脸）与 61.5s（rms_norm 0.18）两张脸余弦 0.0029 → 低质量脸把同侧分布拉到 0 附近，任何基于检测分/尺寸的门都救不回来。
- `rms_norm ≤ 0.10` 能把两个身份分开，但只保留 25/494 张脸（左 18、右 7），时间跨度 12.5–141s，不能直接当逐帧关联门。

## 结果二：质量门控入册 + 参考库匹配（探索性可用）

规则：只用 `rms_norm ≤ 0.10` 的脸建参考库（前 50s：左 16 张、右 5 张）；对之后每张脸取"对本方参考最大余弦 `own`"与"对异方参考最大余弦 `other`"，仅当 `own ≥ τ` 且 `own − other ≥ δ` 才认为有证据关联。

| 指标（后 315 张脸） | 观察 |
| --- | --- |
| `own` | min 0.183 / p05 0.608 / median 0.853 / p95 0.918 |
| `own − other` | min 0.027 / p05 0.438 / median 0.689 / p95 0.762 |
| 本方低于异方（会错关联） | **0 / 315** |

| 操作点 | 关联覆盖 | 歧义保留独立 | 低质量脸（rms_norm>0.12）覆盖 |
| --- | --- | --- | --- |
| τ=0.45, δ=0.10 | 98.4%（310/315） | 0 | 98.2% |
| τ=0.50, δ=0.10 | 97.5%（307/315） | 0 | 97.1% |
| τ=0.60, δ=0.10 | 95.6%（301/315） | 0 | 94.9% |
| τ=0.65, δ=0.10 | 93.0% | 0 | 92.3% |
| τ=0.70, δ=0.10 | 87.6% | 0 | 85.9% |

- 参考库用"多张高质量脸的最近邻"而不是"两两配对"，绕开了低质量脸互相比较时的分布塌陷：这是本次最可迁移的结论。
- 同一视频时间切分只能证明方向与量级；门槛还需要独立配对数据校准，见下一节。

## 结果三：LFW 独立配对验证（1000 对）

素材：Hugging Face `datasets-server` 的 `logasja/lfw` `pairs/test`，按顺序取 label 1 的前 500 对与 label 0 的前 500 对。图片为 LFW 原始 250×250，仅存 `datasets/lfw-pairs/`（忽略目录）；证据只保留余弦与质量统计，不含图像或特征向量。标签语义用数值确认：同人对余弦中位数 0.667、异人对 0.090，方向与"1=同人"一致。

流程：同一隔离路径（旧版 YuNet opset9 → 五点相似变换 → SFace 128 维），1000/1000 对均已检出并对齐成功。

| 指标 | 结果 |
| --- | --- |
| 同人余弦 | min −0.182 / p05 0.450 / 中位 0.667 / p95 0.824 / max 0.912 |
| 异人余弦 | min −0.170 / p05 −0.061 / 中位 0.090 / p95 0.231 / max 0.353 |
| AUC | 0.9939 |
| EER | 1.6%，阈值 0.289 |
| FAR=1% 阈值 | 0.3035（FRR 1.6%） |
| FAR=0.1% 阈值 | 0.366（FRR 1.8%） |

固定阈值下的错误率（1000 对）：

| τ | FAR（异人误关联） | FRR（同人未关联） |
| --- | --- | --- |
| 0.36 | 0 / 500 | 1.8% |
| 0.45 | 0 / 500 | 5.2% |
| 0.50 | 0 / 500 | 8.8% |
| 0.60 | 0 / 500 | 25.2% |

- 与本项目镜像的公开参考阈值 0.363 一致：τ≈0.36 时 FAR 为 0。
- 质量门在 LFW 上几乎没有增益（`rms_norm≤0.10` 筛后 849 对，AUC 0.9944 vs 0.9939）：LFW 本来就是正脸高质量图，质量门解决的是视频域的低质量/侧脸，不是干净图像验证。
- LFW 是"不同时间、不同照片"的困难验证集；视频关联是"同一会话、短时间"的参考匹配，同人余弦更高（视频参考匹配中位 0.853），所以不能把 LFW 的 FRR 直接搬到视频域。

## 修订后的候选操作点

| 参数 | 上一版 | 修订 | 依据 |
| --- | --- | --- | --- |
| 参考库入册质量门 | `rms_norm≤0.10` | 不变 | 视频域分离度最好；只入册 5% 脸但足够 |
| 证据阈值 τ | 0.60 | **0.45（候选；0.50 为保守备选）** | LFW 500 个异人对中 FAR=0；视频覆盖从 95.6% 升到 98.4%，错关联仍为 0 |
| 边距 δ | 0.10 | 不变 | 低质量脸"两方都像"时由边距拒绝，与 τ 解耦 |
| 单一全局阈值 | 不可用 | 仍不可用 | 同侧最低 < 异侧最高 |

若后续场景素材出现"相似人员误关联"，把 τ 回调到 0.50/0.60；这些仍是**待场景验收的候选**，不是冻结值。

## 解释边界

- 视频部分只有一条视频、两个身份、固定构图；同侧标签是夹具标签，不是逐脸真值。
- 视频参考与测试来自同一视频的时间切分（前 50s→后 93s），**不是独立素材**；入册窗口是事后选的。
- LFW 只能校准图像域的身份阈值，不能覆盖换人/相邻/恢复/歧义等**时序场景**；这些仍要按素材协议拍。
- 未覆盖：同位置换人、跨位置相邻双人、原人恢复、歧义候选、已知身份冲突、>2 人、摄像头实时链路。
- 仅本机 PC 结果；板端 OpenCV 4.1.1 下关键点质量与阈值分布未复验。
- 没有保存现场人脸图像；LFW 图片只存忽略目录，证据文件只有余弦/质量汇总。
