# Jetson离线重播600秒稳定性验收（2026-11-01）

**通过本次限定的600秒人工重播资源验收。** 本机及Jetson完整191项测试均通过。自然姿态下更严格的本地事件去重目标仍为预期2、实际12，见[独立业务验收](自然姿态本地事件验收-2026-11-01.md)，整体可靠性未通过。

## 【输入输出定义】

新增`scripts/video_stability_probe.py`与40项受控测试。输入为既有双人原片，输出累计解码/采样、事件协议、真实墙钟、人工循环媒体时间、有限资源快照和源码/媒体/级联哈希。生产算法与参数未修改。

这是重复播放同一片段的压力测试，不是自然重入、现场摄像头或多日运行验收。未读取身份库、保存画面、输出网络事件或替换已有部署。

## 【核心算法逻辑伪代码】

```text
单次初始化检测器与跟踪器
顺序解码 → 显式累计帧序号/12fps → 媒体2Hz采样
每个tick按单调墙钟等待；不足一个节拍的末段也等待到截止时间
EOF仅重开解码器，保留跟踪/事件状态，核对各圈实际长度
真实检测/尺寸过滤/跟踪/事件协议 → 周期RSS/FD/线程快照
finally释放解码器，保留完整或部分进度 → 独立核对运行与资源两个结论
```

## 【异常与边界条件】

有限正时长、采样率与源FPS在解码前校验，设备号、目录和缺失文件拒绝。资源快照、事件明细和调度分桶容量均受限。

独立审查复现并修复了3个工具问题：必要资源指标缺失误通过、途中失败丢失进度、非整节拍时长提前完成。对应新增回归在旧实现上5项失败，修正后40项全过；只读复审未发现新阻断问题。完整视觉测试在本机和Python3.6.9板端各191项通过。

资源门槛在运行前冻结：预热60秒后，RSS增长≤64MiB、FD增长≤2、线程增长≤4。缺指标、无效指标或预热不足必须明确无法判定；进程退出0不能替代资源通过。本轮短时3秒冒烟正确返回预热不足，没有冒充资源验收。
