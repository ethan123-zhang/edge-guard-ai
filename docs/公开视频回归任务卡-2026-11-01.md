# 公开视频离线回归任务卡

用户已授权 DeepSeek 联网找视频并验证，用户正在工作，不需要其提供摄像头或逐轮准备。本卡为已授权的限定实现，不再进行需求确认。

## 【输入输出定义】

只新增 `scripts/video_pipeline_probe.py`、`vision/tests/test_video_probe.py`；不修改生产模块或配置。素材位于忽略目录 `datasets/video-validation/`，来源已由DeepSeek调查并下载。

参数：`--video`、`--json`必填；`--sample-fps`默认2且有限正数；`--start`默认0，`--end`可选且大于start；`--profile`默认jetson_local。视频必须存在、输出父目录须在打开视频前检查。仅输出元数据和事件，不保存截图、不读取人脸库、不发网络、不调用摄像头。

板端实测补充：OpenCV4.1.1读后POS_MSEC比文件真实首帧0多一帧（83.333ms）。增加显式`--time-source {pts,index-fps}`，默认pts；本批两原片已由ffprobe逐帧核实12fps恒定、首帧0，板端验证使用index-fps。原始POS_MSEC仍记录，不自动猜测或静默减偏移。12fps时帧0/6/12必须对应0/500/1000ms。

## 【核心算法逻辑伪代码】

```text
单次顺序解码到EOF，不循环、不sleep
以POS_MSEC为首选媒体时间；合法首帧0必须保留
无效/不前进的PTS用frame_index/fps回退，记录来源和回退数
视频时间2Hz网格抽样，跳过的源帧不调用跟踪器
frame_ts = 1700000000000 + round(media_ms)
真实detector + 尺寸过滤 + FaceTracker(现有配置) + events.face_event/check
保存源帧号/PTS/采样时间/框/轨道前后状态/事件/分层耗时
finally释放视频，保存完整或partial结果
```

真实轨道状态需含id、bbox、last_ts、votes、emitted。记录视频SHA256、源码哈希、原始FPS/帧数/尺寸、EOF或end截断原因、采样数、事件数、错误。此入口验证检测/跟踪/协议，不冒充完整VisionService、身份识别或现场摄像头验收。

## 【异常与边界条件】

禁止使用处理墙钟证明TTL；时间必须单调。FPS无效且PTS不可用则失败。声明帧数与实际解码不一致给出警告，明确EOF可信度。检测异常不能静默当0框。零脸正常；退出0仅代表采样完整且无协议/时间错误，不代表准确率合格。不得放大画面来跨过80px门槛。兼容Python3.6，cv2延迟导入，使纯函数测试不依赖cv2。

## 人工控制视频（脚本完成后生成）

使用双人视频第40秒、原生768×432帧，不裁剪或放大，不以检测输出定义真值。输出仅放忽略目录，用既有OpenCV VideoWriter/mp4v、12fps。

- `control-two-faces-ttl.mp4`：参考帧3秒、全黑0.5秒、参考帧3秒、全黑3秒、参考帧3秒，共12.5秒。2Hz下预期首次2事件，短空白无额外事件，长空白过TTL后再2事件，共4事件。
- `control-confirmation-gap.mp4`：参考帧1秒、全黑0.5秒、参考帧1.5秒，共3秒。2Hz序列为有、有、无、有、有、有。严格连续3帧不得在1.5秒触发，须等到2.5秒。当前累计计票可能提前触发，应如实记录失败，不修算法。

这些是冻结公开视频帧加人工空白的控制素材，不能写成自然遮挡或真人重入。若参考帧不能检出两脸，报告检测层失败，不另找刚好通过的帧。生成命令和`controls.json`保存在素材目录，记录原视频SHA、frame480、片段定义、输出帧数/哈希/预期。
