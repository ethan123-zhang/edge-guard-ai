# 网络方案事实

> 从 `02-environment.md` 拆出（该文件曾超 200 行硬上限）。
> 本页只记**网络拓扑、IP、端口**的事实与约束；硬件与开发环境见 `02`。

## 1. 现场条件与关键约束

**现场条件**：教室 + 手机热点 + 电脑演示。

**关键约束**：手机热点后面是 **NAT**，外部连不进来。

```
门口设备(192.168.43.x) → 手机热点 → 运营商 NAT → 互联网
                                              ✗ 外部连不进来
```

**因此**：

- ❌ 不能让主人端从"外网"连设备
- ❌ 不能依赖云端 MQTT（教室热点未必有外网）
- ✅ **主人端连同一个热点，局域网直连**

## 2. IP：规划值 vs 实测值（**重要，两者不一致**）

| 设备 | 规划值（`docs`） | **实测值** |
| :--- | :--- | :--- |
| 手机热点网关 | 192.168.43.1 | — |
| **鲁班猫5** | ~~192.168.43.10~~ | **192.168.3.214** ✅ 实测 |
| Jetson Nano | 192.168.43.11 | ❌ **至今未实测**（V1 未解冻，不必碰） |
| 主人端 | DHCP 即可 | — |

> ⚠️ **规划值是手机热点网段 `192.168.43.x`，但实测鲁班猫5 在 `192.168.3.214`**（家用/实验室网段）。
> **这两个是同一台设备的不同环境下地址**，不是两台设备——别当成两个 IP 用。
>
> ⚠️ **`config.yaml` 以现场实际为准，切勿硬编码**。现场换网段是常态，
> 这也是"铁律 4：所有阈值外置到配置文件"的适用场景。

**鲁班猫5 连接方式**：用户 `cat`，VSCode Remote-SSH。
