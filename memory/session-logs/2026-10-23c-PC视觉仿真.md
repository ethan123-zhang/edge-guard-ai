## 4. 这一轮踩的坑（已写进 04）

1. **E-48 中文路径**：`cv2.imwrite("E:\\哨兵管家\\...")` 返回 False 且不报错，
   `cv2.imread` 同理 —— 一开始以为"沙箱不让写"，实际是路径编码。已封 `vision/imageio.py`。
2. **E-49 `--jsonl` 顶掉 WS**：日志出口把网络出口替换了，JSONL 全绿但 DB 一条没有。
   改成 `MultiSink`（tee）+ 单测钉死。
3. **E-50 Haar 假阳性**：卫生间墙砖被认成 3 张脸（截图留存）。
   结论：Haar 只能证明"链路通"，不能用来评估召回；且它无关键点 → SFace 必须降级。
4. **E-51 网络全 403**：github/pypi/hf/jsdelivr/modelscope 全挡，模型只能用户浏览器下。
   因此把"双后端降级"做成了第一等公民，而不是"下完模型再说"。

## 6. 设计取舍（值得记住）

1. **`auto` 后端 + 明确日志**：缺模型不崩、不静默，打印"降级成 Haar/None + 去下哪个文件"。
2. **协议字段单独成模块**：`events.check()` 在任何发送前跑一遍，协议错先在日志里见到。
3. **`Sink` 抽象**：WS / JSONL / Null 三种出口，主循环不依赖网络 → 单测不需要起服务。
4. **纯标准库 WS**：板端断网装不了 `websockets`，自己写 100 行反而更可靠。
5. **3.6 语法闸门**：`ast.parse(feature_version=(3,6))` + AST 检查 dataclasses/未来注解，
   把"PC 能跑、板端 SyntaxError"这类问题挡在提交前。

## 7. 经验（可复用）

1. **"文件存在但读不进来"先查路径编码**，别查权限、别查文件损坏（E-48）。
2. **调试出口不能改变主链路**：tee 才是对的，替换一定会骗自己（E-49）。
3. **降级要写进代码，不要写进 TODO**：这次正是因为先做了 Haar/none 降级，
   在"模型一个都没有"的情况下仍然把整条链路验证完了。
4. **验证要分层**：单测证接线、图片源证管线、`--demo` 证协议、板端再证性能。
   一层不通过时，能立刻知道是哪一层的问题。
5. **仿真文档要写"不能证明什么"**（`docs/07` §1），否则很容易把 PC 数字写进答辩。
