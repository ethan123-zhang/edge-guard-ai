# Jetson 可靠性修复与公开视频回归交接

日期：2026-11-01；会话：梳理当前待办事项。

现在已经能在 Jetson 上读取摄像头、检测人脸、跟踪并输出本地陌生人事件；也能用公开视频自动回归，不需要用户在工作中反复配合取景。现在还不能说可靠：连续确认有已复现但未修复的缺陷，熟人识别和双板联调尚未完成。[R00342][R00382][R00483]

公开视频业务结果：自然双人片30～44秒得到2事件，通过；人工短/长空白TTL控制得到1秒两事件、10.5秒两事件，通过；人工“有、有、无、有、有、有”应2.5秒才确认，实际1.5秒触发两事件，失败。[R00483]

人工空白只是可控扰动，不能当作自然遮挡；双人全片12事件不是12个人或12次到访。全片缺少完整逐帧真值，仅作观察。[R00483]

## 接下来做什么

1. 先把确认间断控制片固定成失败回归；冻结连续命中、身份标签切换、TTL内空间轨道保留规则，再限定修改跟踪器。
2. 保留自然双人2事件及TTL控制4事件正例，同时检查确认触发时间。不能靠降低门槛、延长TTL或仅减少事件数通过验收。
3. 修复后独立审查实际差异并上板复验；随后补自然遮挡/重入的完整标注与长期稳定性，再安排熟人识别、同人冷却及双板联调。

未测：熟人识别、同人冷却、GPU、长期稳定性、新光照场景与双板网络输出。视频回归不能替代这些验收。[R00483]；PROGRESS.md。
