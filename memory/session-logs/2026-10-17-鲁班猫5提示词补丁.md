## 2. 遇到的问题与发现（按发生顺序）

### P1. `rkllm_set_chat_template()` 就是系统提示词的官方入口（**本次最重要的发现**）

| 项 | 内容 |
| :--- | :--- |
| **依据** | `rkllm.h:463`：`int rkllm_set_chat_template(LLMHandle, const char* system_prompt, const char* prompt_prefix, const char* prompt_postfix)` |
| **现状** | `llm_demo.cpp:169` 本来就有这行调用，**但是被注释掉的** |
| **含义** | 裸跑没人设**不是模型能力问题，也不是缺 API**，只是这行没启用 |
| **做法** | 补丁里启用它，`prefix`/`postfix` 传空串，交给模型内置 chat template 处理角色标记 |

> ⚠️ **官方那行注释是错的**：它写成 **4 个**字符串参数（多一个 `"<｜endoftext｜>"`），
> 而 1.3.1 头文件只有 **3 个**。**照抄注释取消注释会编译不过。** 这是个很隐蔽的坑。

### P2. Qwen3 的 thinking 模式会偷吃 token 预算（**新识别的混淆变量**）

| 项 | 内容 |
| :--- | :--- |
| **依据** | `rkllm.h:188`：`bool enable_thinking;  /**< Controls whether "thinking mode" is enabled for the Qwen3 model. */` |
| **风险** | 若 thinking 开着，模型先吐推理过程，**48 token 会被推理吃掉**，最终回复看起来"被截断" |
| **后果** | 会把「thinking 占预算」误判成「48 token 不够」或「人设失败」，**结论完全错** |
| **处理** | 补丁**强制 `enable_thinking = false` 并打印该状态**，把混淆变量钉死 |

### P3. 本机有 g++，编译检查不必依赖 WSL（**绕开了沙箱阻塞**）

| 项 | 内容 |
| :--- | :--- |
| **发现** | `C:\Program Files\mingw64\bin\g++.exe`，**g++ 8.1.0**（C++11 够用） |
| **为什么重要** | 原以为要进 WSL 编译验证，而 **WSL 被沙箱挡住**（`Wsl/E_ACCESSDENIED`，即 E-7） |
| **做法** | 写桩文件 `board-pkg/src/compile-check-stubs.cpp` 冒充 `librkllmrt.so`，**不链接真库**即可编译 |
| **收益** | 上板前先在本机排掉语法/类型错误，**省板端来回试错时间** |

> **补充教训**：沙箱还禁止子进程管道（named pipe），所以
> ① Git Bash 跑 `check_gitignore.sh` 直接 `fatal error - couldn't create signal pipe`
> ② 用 .NET `Process` + 重定向 stdin 喂 `exit` 也不行（会挂住）。
> **最后改用「把 main 改名 + 自写 driver + 重定向 stdin 到文件」才跑通初始化路径测试。**

### P4. 验证方式：不靠"能编译"，而靠"每条分支都跑过"

本机实测（桩环境下）逐条验过：

| 用例 | 结果 |
| :--- | :--- |
| 官方原始用法（不传提示词） | ✅ 正常，**向后兼容**，旧 V2 命令照常可用 |
| 带提示词 | ✅ 1425 字节，`set_chat_template` 返回 0，打印指纹 |
| 提示词文件不存在 | ✅ **报错退出(exit=1)**，不会静默裸跑 |
| `history` 参数非法 | ✅ 报错退出(exit=1) |
| `history=on/off` | ✅ 均正确生效 |
| **带 UTF-8 BOM 的提示词文件** | ✅ **BOM 被剥掉**（37→34 字节），首行干净 |

> 最后一条不是凑数：**Windows 上编辑过的文本文件常带 BOM**，
> 若不去掉，提示词开头会多出乱码字节，可能直接带偏模型。

**补丁的 5 处改动**（相对官方）：

1. 新增可选第 4 参数 `system_prompt_file`：**不传 = 与原版完全一致**（向后兼容）
2. 用 `rkllm_set_chat_template()` 注入提示词（官方通道）
3. 强制 `enable_thinking = false` 并打印
4. 打印提示词字节数 + 前 3 行指纹 + 注入返回值（避免"没生效"被误判成人设失败）
5. 支持 `history on|off` 切换 `keep_history`（本轮只用 off，即单轮）

**为什么提示词用「文件」而不是命令行字符串**：§5.1 是多行中文含引号，
过 shell argv 是一堆转义坑；文件最稳。
