# 待验证与开放问题

> **本页是项目的"未验证项看板"**。任何推测、未证实的设计假设都记在这里，
> 验证后**移出本页**，结论写进 `02-environment.md` 或 `03-design-decisions.md`。

## 1. 两个"死亡点"（**最高优先级，不通则项目不成立**）

| # | 待验证 | 怎么验证 | 状态 |
| :--- | :--- | :--- | :--- |
| **V1** | Jetson 能否跑通人脸检测+识别 | OpenCV DNN 加载 YuNet+SFace，对静态图输出人脸数 | ❌ 未开始 |
| **V2** | 鲁班猫5 能否跑通 RKLLM 对话 | 转换 Qwen3-0.6B 为 W8A8，板端 `llm_demo` 能问答 | ❌ 未开始 |

> V1 通了记下单帧耗时；V2 通了记下 tokens/s。**这两个数字答辩要用。**

## 2. 待验证的技术假设

| # | 假设 | 风险 | 状态 |
| :--- | :--- | :--- | :--- |
| V3 | Jetson 自带 OpenCV ≥ 4.5.4（含 `FaceDetectorYN`） | 若不含需装 pip 版，可能覆盖系统库 | ❌ 未验证 |
| V4 | Qwen3-0.6B 在 RK3588 上首字响应 1~2 秒 | 若超 3 秒，对话体感崩，需换更小模型或缩短 prompt | ❌ 未验证 |
| V5 | 0.6B 模型能稳定输出符合 JSON schema 的槽位 | 小模型抽取不稳，故已设计规则优先兜底 | ❌ 未验证 |
| V6 | 新买的阵列麦能 Linux 免驱识别 | 若不能，需换货或走 I2S（有兼容风险） | ❌ 未购 |
| V7 | 播报闭麦能彻底消除自问自答 | 若不彻底，需加大 `post_tts_delay_ms` 或上硬件 AEC | ❌ 未验证 |
| V8 | 端到端响应 < 3.5 秒 | 预算是 2.0~3.3 秒（VAD 700ms + ASR 400~800ms + LLM 600~1200ms + TTS 300~600ms） | ❌ 未验证 |
