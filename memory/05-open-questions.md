### 2.1 实测暴露的两个问题（**2026-10-15**）

**① `max_new_tokens` 在 `docs/03` 里有三个矛盾值** —— ✅ **已统一为 48**

| 原位置 | 原值 |
| :--- | :--- |
| §5.3 总结提示词 | 48 |
| §6 延迟预算表 | 128 |
| §6 降级建议 | "降到 64" |

**为什么必须改**：按实测 31.65 tok/s 反推，**128 token = 4 秒**，
光 LLM 一项就吃穿端到端预算。设计要求"每次 1~2 句话"≈30~45 token，**48 够用且安全**。

**② 裸跑 `llm_demo` 时模型不符合人设**（**待接入提示词后复验**）

实测对话：
```
user:  你好，请问这是王先生家吗？
robot: 您好，我是您的助手。请问您是想了解王先生的家吗？或者有什么其他问题需要帮助呢？
```

这**正是 `docs/03` §5.1 明令禁止的表达**（"用口语…不要说'您好，我是人工智能助手'这种客套话"）。
**原因**：`llm_demo` 是裸跑，**没有加载系统提示词**，模型用了默认助手人格。
⚠️ **接入 §5.1 提示词后需复验**，确认人设与长度都受控。
